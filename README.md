Test Flow
  1. 유저가 포인트를 사용한다. (userId, usePoint)
    if ( 사용 금액 ≤ 0 ) 
      - 에러 반환
      - 사용 금액 재입력 유도
        
    elif ( 유저 id 조회 )
        if ( 유저 테이블에 유저 id 가 없다. )
          1) 에러
          2) 아이디 생성할 것인지 사용자에 묻고 충전 유도
            - 아이디가 없습니다. 가입하시겠습니까 ?
            - 충전하시겠습니까 ?
        
        elif ( 유저 테이블에 유저 id 가 있다. )
          - 잔액 조회
            if (사용 금액 ≤ 잔액)
              1) 잔액 -= 사용 금액
              2) 유저 포인트 테이블에 포인트 잔액 갱신
              3) 포인트 히스토리 테이블에 거래 추가
            
            else (사용 금액 > 잔액)
              1) 에러 
              2) 사용 가능한 포인트 잔액 고지
              3) 사용할 포인트를 다시 입력해주십시오.
    
  2. 유저가 포인트를 충전한다. (userId, chargePoint)
    if ( 충전 금액 ≤ 0 )
      1. 에러 반환
      2. 충전 금액 재입력 유도
        
    elif ( 유저 id 조회 )
        if ( 유저 테이블에 유저 id 가 없다. )
          - 에러
          - 유저 id를 새로 생성하고 chargePoint 만큼 충전한다.
          - 유저에게 아이디를 생성할 것이냐 묻는다.
              1) 아이디가 없습니다. 생성하시겠습니까 ?
              2) 충전하시겠습니까 ?
        
        elif ( 유저 테이블에 유저 id 가 있다. )
          - 잔액 조회
              if ( 충전 금액 + 잔액 > 충전 최대 한도 )
                1. 에러 반환
                2. 충전 금액 재입력 유도
            
              else 
                1. 잔액 += 충전 금액
                2. 유저 포인트 테이블에 포인트 잔액 갱신
                3. 포인트 히스토리 테이블에 거래 추가
